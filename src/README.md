**Status:** Reserved

# Purpose

The Source Code repository contains the production implementation
of the Ziva ecosystem.

This directory hosts all executable components developed in
accordance with the approved architecture, engineering standards
and governance policies.

---

# Objectives

This repository exists to:

- organize production source code
- preserve architectural boundaries
- support scalable development
- improve maintainability
- enable deterministic implementation
- facilitate engineering reviews

---

# Scope

The source tree may contain:

- domain modules
- shared libraries
- infrastructure components
- platform services
- integration adapters
- common utilities

Every source file must comply with the approved ADRs,
Engineering Rules and repository policies.

---

# Governance Principles

Implementation must always respect:

- Documentation First
- Architecture First
- Repository Materialization Policy
- Decision Escalation Policy
- Engineering Rules

No implementation may contradict approved architecture.

---

# Repository Structure

The internal structure of `/src` will evolve according to
approved ADRs and implementation plans.

New directories may only be introduced after architectural approval.
